# Memority

## Web development project

_Memory_ game made using:

<ul>
<li>HTML</li>
<li>CSS</li>
<li>JS</li>
</ul>

<br>

This game features A11y ARIA, Fisher-Yates shuffle, and asynchronous tasks.

## How to use

Press the "Start" button and click two cards.<br>
If the two cards match, the cards become green.<br>
If not, they will be hidden back.
